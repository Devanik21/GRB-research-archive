# Security Policy

## Supported Versions

Please see our documentation for information regarding supported versions of this software. We generally only support the latest main branch version.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to the maintainers. All security vulnerabilities will be promptly addressed.

Please do not report security vulnerabilities through public GitHub issues. Instead, report them privately via email.

Once you have reported the vulnerability, the team will evaluate it and, if verified, release a patch as quickly as possible. We will also publish a security advisory acknowledging your contribution if you so desire.
